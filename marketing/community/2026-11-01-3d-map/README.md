# 뽐뿌·블라인드 게시용 이미지 — 단지 주변 3D (2026-11-01)

아파트 인사이트 회원 기능 "단지 주변 3D"(앱 단지 상세의 `주변 3D` 버튼) 공개에 맞춘 커뮤니티 게시용 이미지와 글 초안이다. 화면은 모두 실제 앱 캡처이며 생성 모델로 다시 그리지 않았다.

| `03-jamsil-3d-square.jpg` | 1080 × 1080 | 썸네일이 정사각형으로 잘리는 곳(블라인드 목록 등). 세로가 짧아 보조 문구를 뺐다 |

캡처 원본은 apt-insights 저장소 `design/store-listing/captures/`(3D 전경은 `2026-11-01/viral-2km-*.png`, 3D 앱 화면은 `2026-11-01/phone-3d-map.png`, 실거래는 `member/`, 전망은 `2026-10-01/`)이다. 다시 만들 때:

```bash
APT_INSIGHTS_DIR=../apt-insights node marketing/community/2026-11-01-3d-map/build.mjs
```

## 지켜야 할 표현

- 실제 제공 기능만 쓴다. 단지 주변 3D는 **로그인 후 이용**이고, 처음 여는 단지는 지도를 만드는 데 몇 분 걸릴 수 있다.
- 랜드마크는 단지 반경(최대 2km) 안에 있을 때만 나온다. "어느 단지에서나 롯데타워가 보인다"처럼 쓰지 않는다. 롯데월드타워는 단순화한 3D 모형이므로 "실물 같은 모형"이라고 쓰지 않는다.
- 전망은 예상 범위·참고 자료다. 가격·수익 보장, 매수·매도 추천, 정확도 순위, 경쟁 서비스 비교를 쓰지 않는다([스토어 카피 원칙](https://github.com/seogi1004/apt-insights/blob/main/docs/business/STORE_LISTING.md) §1과 같다).
- 커뮤니티 규칙상 홍보글 게시판·말머리가 따로 있으면 그곳에 올린다. 같은 글을 여러 게시판에 반복해서 올리지 않는다.

## 글 초안

### 뽐뿌 (부동산포럼 또는 자유게시판의 홍보 허용 말머리)

제목

```text
아파트 주변을 3D로 볼 수 있게 만들어 봤습니다 (롯데타워 보이는 잠실 단지 예시)
```

본문

```text
혼자 만들고 있는 아파트 앱에 단지 주변을 3D로 보는 기능을 붙였습니다.

단지를 고르면 반경 500m·1km·2km 안의 건물을 입체로 세우고
지하철역·학교·공원·병원과 랜드마크를 한 화면에 보여 줍니다.
사진은 롯데월드타워가 반경 안에 들어오는 잠실 단지 예시입니다.

원래는 실거래 확인과 1년 뒤 예상 범위를 보는 앱이라
3D 지도와 실거래·전망을 같은 단지에서 이어서 볼 수 있습니다.
(3D는 로그인 후 이용, 처음 여는 단지는 지도를 만드는 데 몇 분 걸려요)

전망은 통계로 계산한 참고 범위라 실제 가격과 다를 수 있습니다.
써 보시고 불편한 점 알려 주시면 고치겠습니다.
```

### 블라인드 (부동산 라운지)

제목

```text
롯데타워 보이는 단지, 주변을 3D로 둘러보는 기능 만들었어요
```

본문

```text
개인적으로 만들고 있는 아파트 앱에 "단지 주변 3D"를 넣었습니다.

- 단지 반경 500m~2km 건물을 입체로
- 역·학교·공원·병원, 반경 안 랜드마크(롯데월드타워 등)
- 같은 단지의 최근 실거래와 1년 뒤 예상 범위도 이어서

3D는 로그인 후 쓸 수 있고, 전망은 참고용 통계 범위입니다.
임장 전에 동네 감 잡는 용도로 써 보시고 피드백 부탁드려요.
```

링크는 각 커뮤니티의 외부 링크 규칙을 확인한 뒤 본문 끝에 붙인다(앱 스토어 또는 https://apt-insights.com).
