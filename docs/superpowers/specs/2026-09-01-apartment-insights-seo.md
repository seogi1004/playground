# 아파트 인사이트 검색 노출 보완 명세

## 목표

`alvin.ing` 블로그가 아파트 가격·실거래·예측을 찾는 사람에게 유용한 정보 허브가 되고, `아파트 인사이트` 서비스로 자연스럽게 이어지도록 기존 콘텐츠와 탐색 구조를 보완한다.

## 범위

- 홈페이지에 신규 아파트 예측 콘텐츠 허브 추가
- 기존 통계 입문 글을 예측 콘텐츠의 상위 가이드로 확장
- 가격 범위 관련 글의 검색 의도 분리
- 신규 글의 발행일·내부 링크·공개 링크 점검
- 정적 `llms.txt`를 생성 결과와 동기화
- 아파트 인사이트 공식 홈페이지에서 블로그를 발견할 수 있는 링크 추가

## 성공 기준

- 홈페이지에서 신규 5편과 공개 예측 체험으로 이동할 수 있다.
- 통계 입문 글에서 신규 5편으로 이동할 수 있고 서비스 링크가 있다.
- 기존 가격 범위 글은 개념 설명, 신규 범위 글은 실제 결과 화면 해석으로 역할이 구분된다.
- 공개 콘텐츠에 내부 모델·운영 용어가 노출되지 않는다.
- 빌드, 타입 검사, 공개 카피 검사, SEO 검사가 통과한다.
- Cloudflare Pages 배포 후 핵심 URL이 HTTP 200으로 응답한다.
