# 아파트 인사이트 1주차 콘텐츠 발행 계획

> 작성일: 2026-08-31
>
> 목표: `apps/www`의 최신 공개 체험 기능을 부동산·아파트 검색 질문에 자연스럽게 연결하고, 첫 주에 검색형 글 5편을 발행한다.

## 운영 원칙

- 20편을 한꺼번에 만드는 대신 1주차에는 5편만 공개한다.
- 제목과 첫 문단은 서비스 홍보보다 독자가 검색한 질문에 먼저 답한다.
- 가격·예측·시장 정보는 기준일과 해석 한계를 함께 적는다.
- 공개 체험은 가입 없이 시군구와 단지명을 검색해 최근 대표 시세와 12개월 뒤 예상 범위를 확인하는 흐름으로 설명한다.
- 예측 결과는 참고용 분석이며 가격·거래 가능성·수익을 보장하지 않는다는 고지를 각 글에 포함한다.
- 내부 모델 단계, 분류 체계, 운영 경로, 저장 필드와 같은 구현 세부사항은 공개 글에서 제외한다.

## 글 사이의 내부 링크 구조

- 1번은 2번·3번·5번으로 보낸다.
- 2번은 기존 가격 층위 글과 3번으로 보낸다.
- 3번은 1번·4번·5번으로 보낸다.
- 4번은 기존 아파트 통계 입문 글과 1번·5번으로 보낸다.
- 5번은 1번·3번·공식 미래가격 가이드로 보낸다.

이 구조는 공개 체험 기능을 모든 글에 반복해서 홍보하지 않고, 독자가 읽은 질문에 맞는 다음 정보로 이동시키기 위한 것이다.

## 발행 전 검수

1. 각 글의 공개 출처·기준일·지역 범위·면적 조건을 확인한다.
2. 가격·세금·정책·AI 관련 표현에 필요한 면책을 확인한다.
3. 내부 모델 식별자와 금지 용어가 없는지 `npm run check:public`으로 검사한다.
4. Docusaurus 빌드로 canonical, BlogPosting 구조화 데이터, RSS, Atom, JSON Feed, 사이트맵을 생성한다.
5. `npm run check:seo`로 빌드 결과를 확인한 뒤 Cloudflare Pages에 배포한다.
6. 배포 후 Google Search Console과 네이버 서치어드바이저에서 사이트맵·RSS·색인 상태를 확인한다.

## 1주차 성과 기준

- 5개 글 모두 빌드 결과에 포함되고 canonical URL이 생성될 것
- 글마다 관련 글 3개 이상과 주 CTA 1개가 있을 것
- 검색 노출수·클릭률·평균 검색순위·색인 여부를 글별로 기록할 것
- 공개 체험 진입은 보조 지표로 기록하되, 검색 노출과 글 간 이동을 우선 평가할 것
- 2주차 주제는 1주차에서 실제로 노출·클릭된 검색 의도와 내부 링크 이동을 보고 결정할 것
